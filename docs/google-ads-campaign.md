## Policy Issues & Appeal

### Issue
- **Policy violation:** Free desktop software
- **Reason:** Google AI flagged ad for containing "Free" + PDF-related language
- **Status:** Appeal submitted on April 6, 2026

### Appeal reason
> "Invoice-Quickly is a web-based invoice generator, not downloadable desktop software. Users access it through a browser with no installation required."

### Resolution options (if appeal rejected)
1. Remove all instances of "Free" from ad copy
2. Create a new ad with neutral language only
3. Apply for Google's Free Desktop Software certification
